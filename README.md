E-Commerce Sales Analysis Dashboard Using Microsoft Excel

Project Overview

This project presents an interactive E-Commerce Dashboard built using Microsoft Excel to analyze order patterns, product categories, customer demographics, delivery performance, and customer ratings.

The dashboard transforms raw e-commerce data into visual insights to support business analysis and data-driven decision-making.

Dashboard Features

- Order Mode Analysis: Explore orders across App, Instagram, Partner App, Target.com, and Website.
- Quantity and Amount Trends: Analyze changes in order quantity and sales amount over time.
- Customer Demographics: Understand the distribution of customers by gender and order mode.
- Product Category Analysis: Compare product categories based on order quantities.
- Delivery Performance: Analyze delivery time and days taken to deliver orders.
- Order and Rating Analysis: Explore order patterns and customer ratings.
